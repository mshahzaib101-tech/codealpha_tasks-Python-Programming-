* **Description:** A classic word-guessing game.

### 2. Stock Portfolio Tracker
* **Description:** A tool to track investments based on stock symbols and quantities.
* **Key Features:** Uses a dictionary for predefined stock prices, calculates total investment, and saves the final report to a text file.
* **Concepts Used:** `dictionaries`, `file handling`, `arithmetic`, `input/output`.

### 3. Basic Chatbot
